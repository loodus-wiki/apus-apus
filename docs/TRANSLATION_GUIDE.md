# TRANSLATION GUIDE — Сайт помощи стрижам Apus apus

> Этот документ — справочник для переводчиков и LLM-агентов.
> Русский раздел (`ru/`) является «источником правды».

---

## Структура проекта

```
docs/
├── ru/          ← источник правды (16 файлов)
├── est/         ← эстонский перевод
├── ua/          ← украинский перевод
└── _data/       ← navigation-*.yml, sticky_menu-*.yml
```

**Не переводить:**
- `_drafts.md` — временные черновики, убираются автоматически
- `_emergency.md` — убран из навигации, ожидает доработки
- `cure-swift.md` — медицинский файл, переводится отдельно моделью Opus
- `more-information.md` — содержит `no_translate: true`, наполняется вручную под регион

| Термин | Статус | Комментарий |
|--------|--------|-------------|

## Стиль и тон

- **EST:** Живая речь реабилитаторов (Eesti Metsloomaühing, EOÜ). Не канцелярит.
- **UA:** Мова волонтерів та орнітологів (УТОП). Перевага «серпокрилець», але «стриж» допустимий.
- **Все языки:** Не смягчать категоричные предупреждения. «Категорично заборонено», «ніколи», «только» — оставлять.

## Конвенции разметки

### `no_translate: true` в front matter

Страницы с этим маркером не требуют перевода — их содержание специфично для региона и наполняется вручную:

```yaml
---
no_translate: true
---
```

Пример: `more-information.md` — ссылки на местные организации.

### Блоки `<!-- region:... -->`

Для блоков, специфичных по региону/лекарствам. Комментарии **на языке страницы**:

```html
<!-- region:medications — In original: Левомеколь. Available in Russia. -->
...текст...
<!-- /region:medications -->

<!-- piirkond:ravimid — Originaalis: Levomekol. EL-is pole saadaval, kasutage Fucidin/Baneocin. -->
...текст...
<!-- /piirkond:ravimid -->

<!-- область:ліки — В оригіналі: Левомеколь. Доступний в Україні. -->
...текст...
<!-- /область:ліки -->
```

### Комментарии к медиа-файлам

```html
<!-- media:localized — видео/фото имеет версию на языке страницы -->
<!-- media:pending-localization — нужна локализация, пока общая версия -->
```
