# Розміщення пташеняти у чуже гніздо

Підкладання пташеняти серпокрильця до прийомних батьків у дикій природі — це найкращий спосіб виростити здорового птаха, якщо є така можливість.

## Умови для успішного підкладання

1. **Вікова відповідність**: Пташеня, яке підкладають, має бути того ж віку (або відрізнятися максимум на 2–3 дні) від пташенят у прийомному гнізді.
2. **Кількість пташенят у гнізді**: Загальна кількість пташенят у прийомному гнізді після підкладання не повинна перевищувати 3 осіб (оптимально 2–3).
3. **Стан здоров'я**: Пташеня має бути повністю здоровим, без інфекцій, паразитів та травм, добре вгодованим.
4. **Час проведення**: Підкладання проводиться у світлий час доби, коли батьки відсутні у гнізді.

## Застереження

Не намагайтеся підкладати пташенят, якщо у вас немає впевненості у доступності гнізда та безпеці процедури для вас і для птахів.
