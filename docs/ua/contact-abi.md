# Куди звернутися за допомогою в Україні

Якщо ви знайшли серпокрильця і йому потрібна допомога, зв'яжіться з волонтерами або реабілітаційними центрами.

## Facebook-групи допомоги серпокрильцям

Напишіть допис або особисте повідомлення в одну з груп (обов'язково вкажіть ваше місто!):

- <a href="https://www.facebook.com/groups/swifts.information/" target="_blank" rel="noopener noreferrer">Стрижі: інформація та допомога — Facebook (відкривається у новому вікні)</a>
- <a href="https://www.facebook.com/groups/is.ruk.v.nebo/" target="_blank" rel="noopener noreferrer">Їс рук в небо! — Facebook (відкривається у новому вікні)</a>

## Центри реабілітації та організації

- <a href="https://www.instagram.com/freewingslviv/" target="_blank" rel="noopener noreferrer">«Вільні крила» (Львів) — Instagram (відкривається у новому вікні)</a>  
  Центр реабілітації диких птахів.
- <a href="https://wwf.ua/?311751%2Fwild-animals-what-to-do=" target="_blank" rel="noopener noreferrer">Центри реабілітації диких тварин — WWF Україна (відкривається у новому вікні)</a>  
  Повний перелік центрів та організацій по регіонах України.

## Що вказати при зверненні:

1. Ваше місто
2. Вагу птаха на кухонних вагах
3. Фото серпокрильця зверху на світлому тлі та відео поведінки
4. Наявність пошкоджень чи крові
