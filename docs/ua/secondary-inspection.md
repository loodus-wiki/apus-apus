# Вторинний детальний огляд

Після первинного огляду та надання першої допомоги необхідно провести детальний вторинний огляд серпокрильця.

## Покроковий чек-лист огляду

### 1. Огляд голови та очей
- **Очі**: повинні бути повністю відкриті, опуклі, блискучі, без каламутності, виділень чи набряків повік. Зіниці однакового розміру, однаково реагують на світло.
- **Дзьоб**: цілий, без тріщин, сколів та деформацій. Слизова рота рожева, без білого чи жовтявого нальоту, без в'язкого слизу.
- **Вушні отвори**: чисті, без слідів крові чи виділень.

### 2. Огляд крил та суглобів
- Розправте кожне крило по черзі.
- Перевірте симетричність, відсутність припухлостей, гематом та крововиливів.
- Перевірте стан махових пер: відсутність заломів, випадіння чи пошкодження стрижнів.

### 3. Огляд лап та пальців
- Усі 4 пальці спрямовані вперед.
- Кігті цілі, лапки теплі.
- Перевірте відсутність переломів та порізів.

### 4. Огляд тулуба та кіля
- Оцініть угодованість за кільовою кісткою (U-подібна — норма, V-подібна — виснаження).
- Пороздувайте пір'я на животі та спині: перевірте відсутність паразитів (пухопероїдів, кровососок), саден, гематом та ранок.

### 5. Оцінка дихання та поведінки
- Дихання рівне, частота вища, ніж у людини. Відсутність сипів, хрипів та дихання з відкритим дзьобом.
- Птах не повинен бути апатичним чи мати тремор голови.
